# Aula 01 — Mini exercício

## 1. Três coisas que quero aprender

1. Aprender a trabalhar com branches e Pull Requests em projetos colaborativos.
2. Entender como funciona a revisão de código e como responder a sugestões.
3. Aprender a organizar documentação técnica utilizando Markdown e GitHub.

## 2. Resultado observado

Consegui criar uma branch, adicionar um arquivo Markdown, realizar um commit e publicar a branch no meu Fork.

Também me ajudou a fixar a diferença entre commit, push e Pull Request.

## 3. Explicação

O commit registra as alterações no histórico da branch local.

O push envia os commits para o repositório remoto.

O Pull Request permite solicitar a revisão e a possível integração das alterações à branch principal.

## 4. Dificuldades encontradas

Tive dificuldades com as permissões do repositório e com a diferença entre históricos de commits.

Aprendi que o Fork permite trabalhar em uma cópia própria do projeto e propor alterações ao repositório original por meio de Pull Request.
