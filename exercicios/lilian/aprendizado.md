## 3. Explicação

Uma branch é uma ramificação de um projeto para que você posso fazer alterações, adições de funcionalidade, correções... sem alterar projeto principal.

O commit faz o registro das alterações feitas no código.

O push é responsável por enviar o projeto do repositório local para o repositório remoto.

O pull request permite a revisão do código pela equipe. Assim, podem ser feitas correções ou melhorias antes de ir para main.
