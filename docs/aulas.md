# Aulas e entregas

As datas intermediárias são propostas, sujeitas à disponibilidade do grupo. Cada aula tem uma prática A e uma contribuição B. O [critério de pronto](construcao-incremental.md) define a entrega final.

| Aula | Tema | Resultado integrado |
| --- | --- | --- |
| [01](aulas/aula-01.md) | Projeto e primeira contribuição | Repositório organizado, com primeiro fluxo de contribuição funcionando. |
| [02](aulas/aula-02.md) | Python: texto, valores e condições | Validação reutilizável pronta para a tela de mensagens. |
| [03](aulas/aula-03.md) | Funções, listas e laços | Contrato de dados e funções básicas preparados para leitura do CSV. |
| [04](aulas/aula-04.md) | CSV, pandas e qualidade dos dados | Leitura e preparação dos dados reais funcionando e documentadas. |
| [05](aulas/aula-05.md) | Treino, validação e teste | Treino, validação e teste definidos para todos os modelos. |
| [06](aulas/aula-06.md) | Primeiro classificador de mensagens | Baseline e primeiro modelo reais treináveis e avaliáveis. |
| [07](aulas/aula-07.md) | Comparação, métricas e Joblib | Comparador de modelos completo, com persistência e inferência reutilizável. |
| [08](aulas/aula-08.md) | Interface do comparador em Streamlit | Aplicação utilizável com classificação e comparação reais. |
| [09](aulas/aula-09.md) | Reprodução e ensaio da entrega | Versão candidata reproduzida, demonstrável e revisada. |
| [10](aulas/aula-10.md) | Demonstração e retrospectiva | Projeto 04 pronto para demonstração e uso educacional, com entrega identificada. |
